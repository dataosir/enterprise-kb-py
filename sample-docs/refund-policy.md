# 企业退款政策

> 版本：v2.1 | 生效日期：2025-01-01 | 适用：全体付费用户

## 1. 适用范围

本政策适用于通过官方渠道购买的所有付费产品与服务，包括 SaaS 订阅、企业版授权、增值模块。

以下情况不适用本政策：
- 免费试用期产品
- 通过第三方代理商购买且代理商有独立退款条款的订单
- 已开具增值税专用发票且超过 30 日的订单

## 2. 退款条件

### 2.1 全额退款

满足以下全部条件可申请 **100% 全额退款**：
1. 购买后 **7 个自然日内** 提出申请
2. 产品核心功能 **未使用超过 3 次**
3. 未产生任何 API 调用费用

### 2.2 部分退款

| 使用时长 | 退款比例 | 说明 |
|---------|---------|------|
| 8~30 天 | 70% | 按未使用天数折算 |
| 31~90 天 | 50% | 需说明退款原因 |
| 超过 90 天 | 不支持 | 可转为企业账户余额 |

### 2.3 不可退款情形

- 定制化开发项目（合同另有约定除外）
- 因违反服务协议被封禁的账户
- 促销/折扣活动期间购买的特价产品

## 3. 退款流程

1. **提交申请**：登录控制台 → 订单管理 → 申请退款，填写原因
2. **审核**：客服团队 **3 个工作日内** 完成审核
3. **退款到账**：审核通过后 **5~10 个工作日** 原路退回

紧急退款可联系客服热线：400-888-0001（工作日 9:00-18:00）

## 4. 特殊说明

- 企业年付客户可申请 **按比例退款**，需提供采购合同编号
- 因我方系统故障导致服务不可用超过 24 小时，自动触发 **服务时长补偿**，无需用户申请
